# TaskCodeTwo

TaskCode 2: metodología de tareas con revisión por pares de agentes, Git
determinista y puertas de calidad impuestas por la plataforma (GitHub y
GitLab), pensada para equipos de trabajo. Se instalará igual que TaskCode,
como plugin del marketplace de Claude Code.

> **Estado: en construcción.** Este repo se desarrolla con
> [TaskCode 0.16](https://github.com/charliebk/TaskCode): sus tareas están en
> `tareas/` y se trabajan con `taskctl`. Cuando la 2.0 pueda llevar su propio
> desarrollo, este repo se actualizará a ella (tarea F4-5 del plan).
